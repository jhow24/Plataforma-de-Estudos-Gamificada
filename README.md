# Circuito do Conhecimento — Quiz de Ensino Médio

Jogo de perguntas e respostas com gamificação, em português, para revisão de conteúdos do Ensino Médio. O pacote mantém o mesmo banco de questões em três formatos: site web, Google Colab/Python e GameMaker/GML.

## O que há no jogo

* **100 questões**, distribuídas em cinco níveis de dificuldade crescente: Calouro, Explorador, Estrategista, Mestre e Lenda.
* **20 perguntas por nível**, sorteadas em ordem aleatória e sem repetição dentro de cada tentativa.
* Oito áreas: Matemática, Biologia, Química, Física, História, Geografia, Língua Portuguesa e Inglês.
* Cada acerto rende **100 XP de avanço**; a cada terceiro acerto consecutivo há **+25 XP de combo**.
* Cada erro rende **+20 XP de participação**, com explicação, mas não conta para liberar o nível seguinte.
* A meta é **300 XP de avanço no nível atual**. Se ainda não alcançou a meta ao terminar as 20 questões, o jogador pode repetir o nível; perguntas já pontuadas corretamente não concedem XP de avanço outra vez.
* Não há cronômetro, cadastro ou envio de respostas. O progresso da campanha permanece somente durante a sessão aberta.
